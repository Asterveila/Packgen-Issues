# PackGen Issues Page [ENG]
Use this github repository to report any bugs, issues, and make any suggestions to the PackGen website, used to generate Geometry Dash Menu Recolors automatically.
This will also hold the PackGen Changelog and Detailed Mod Support list sub-website soon.

## Guidelines
While the repo is pretty straight-forward and shouldn't need much guidance, there's a few things to consider regarding what you should submit.

- **Bug Reports**: Please make sure the bug is ACTUALLY related to PackGen. If your bug is some textures being all weird, please verify there isn't any other loaded texture pack that could potentially be interfering with it.
- **Feature Suggestions**: Please keep your suggestions realistic. While i know i am cool as hell, i cannot make your menus be animated rainbow colors and make the difficulty faces blink and speak to you.
- **Mod Support**: Please make sure if you're asking for a mod to be supported, that you're *installing your PackGen packs correctly.* PackGen packs are designed to be applied via the ***" Texture Loader"*** geode mod, if you're using other methods, don't be surprised if stuff breaks. Not my fault.

# Página de Issues de Packgen [ESP]
Utiliza este repositorio de github para reportar bugs, problemas, y hacer cualquier sugerencia que tengas para la página de PackGen, utilizada para generar recolores del menú default de Geometry Dash automáticamente.
Esta repo también será pronto host de las sub-páginas de PackGen Changelog (lista de cambios) y una lista detallada de Mods Soportados.

## Reglas
Aunque este repo sea muy fácil de comprender para que es y no debería necesitar una lista enorme de reglas, SI hay algunas cosas que considerar antes de abrir un issue.

- **Bug Reports**: Porfavor asegúrate de que tu bug sea REALMENTE un problema de PackGen. Si tu bug es, por ejemplo, texturas que se ven raras/rotas, porfavor verifica que no sea algún otro texture pack que tengas activo interfiriendo con el de PackGen.
- **Sugerencias**: Porfavor, mantén tus sugerencias realistas. Sé que soy chingonsisima, pero no puedo ni quiero hacer que tus menús tengan animación RGB y hacer que las caras de dificultad parpadeen y te hablen.
- **Soporte de Mods**: Porfavor asegurate de que si estás pidiendo soporte para las texturas de un mod, que *tengas instalado CORRECTAMENTE tus texture packs de PackGen.* Los packs que PackGen genera están diseñados para ser aplicados con el mod de Geode ***"Texture Loader"***, si estás usando otros métodos, que no te sorprenda si hay cosas rotas, no es mi culpa.
